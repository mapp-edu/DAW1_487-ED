# UP3 · Control de versiones y trabajo colaborativo

Ningún equipo profesional trabaja sin control de versiones. En esta unidad aprenderás Git desde la terminal y desde el IDE, trabajarás con ramas y colaborarás en GitHub mediante *pull requests* y revisiones de código. A partir de aquí, **todas las entregas del módulo se hacen en un repositorio**.

| | |
|---|---|
| **Resultado de aprendizaje** | RA4 · Optimiza código empleando las herramientas disponibles en el entorno de desarrollo |
| **Criterios** | f (control de versiones integrado en el IDE) y h (repositorios remotos y desarrollo colaborativo) |
| **Duración** | 15 horas · semanas 7–11 · 1.ª evaluación |
| **Peso** | La UP3 aporta el 50 % de la nota del RA4 (31 % del módulo) |

## Objetivos

- Explicar para qué sirve un sistema de control de versiones y diferenciar el modelo centralizado del distribuido.
- Usar Git desde la terminal: repositorio, área de preparación, *commits*, historial y deshacer cambios.
- Crear, fusionar y eliminar ramas, y resolver conflictos.
- Trabajar con repositorios remotos en GitHub: clonar, sincronizar, *pull requests* y revisión de código.
- Aplicar una estrategia de ramificación (GitHub Flow).
- Realizar las mismas operaciones desde IntelliJ IDEA y VS Code.
