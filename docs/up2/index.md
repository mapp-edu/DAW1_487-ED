# UP2 · Entornos de desarrollo integrados

El entorno de desarrollo es la herramienta con la que pasarás más horas. En esta unidad instalarás y compararás dos entornos muy diferentes, IntelliJ IDEA y Visual Studio Code, aprenderás a adaptarlos a tu forma de trabajar y generarás ejecutables con ellos.

| | |
|---|---|
| **Resultado de aprendizaje** | RA2 · Evalúa entornos integrados de desarrollo analizando sus características para editar código fuente y generar ejecutables |
| **Criterios** | a, b, c, d, e, f, g |
| **Duración** | 9 horas · semanas 4–6 · 1.ª evaluación |
| **Peso del RA** | 9 % de la nota del módulo |

## Objetivos

- Identificar las funciones y los componentes de un IDE, y distinguir entre IDE y editor de código.
- Instalar entornos libres y propietarios y configurar sus actualizaciones.
- Añadir, configurar y eliminar extensiones y *plugins*.
- Personalizar el entorno (temas, atajos, estilo de código, plantillas) y automatizar tareas repetitivas.
- Generar ejecutables de un mismo código con varios entornos y de varios lenguajes con un mismo entorno.
