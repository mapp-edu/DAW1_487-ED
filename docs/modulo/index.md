## Qué aprenderás

El módulo te da las herramientas del día a día de un equipo de desarrollo profesional:

- entender qué ocurre desde que se escribe el código hasta que se ejecuta y cómo se organiza un proyecto de software, también con métodos ágiles;
- instalar, configurar y automatizar entornos de desarrollo;
- versionar el código y colaborar con Git y GitHub;
- diseñar pruebas, automatizarlas y depurar programas;
- mejorar el código (refactorización y análisis estático), documentarlo e integrarlo de forma continua;
- leer y elaborar diagramas UML de estructura y de comportamiento.

## Metodología en modalidad semipresencial

- **Publicación quincenal.** Cada quince días se publica en este sitio y en Aules todo lo que debe trabajarse en ese periodo: apuntes, ejemplos y tareas.
- **Tutorías colectivas presenciales.** Sirven para explicar los conceptos clave, resolver dudas y hacer en grupo las prácticas guiadas. La asistencia no es obligatoria, pero sí muy recomendable.
- **Tutorías individuales.** Se piden con cita previa en Aules y pueden ser presenciales o telemáticas.
- **Foros de dudas** por unidad en Aules. Antes de preguntar por mensaje privado, consulta el foro: tu duda puede servir a otras personas.
- **Entregas en repositorio.** Desde la UP3, las tareas se entregan como repositorio de GitHub; en Aules se sube el enlace y, si se pide, un PDF.
- **Aprender haciendo.** Cada unidad combina una explicación breve, un ejemplo guiado y una tarea práctica que se califica con rúbrica.

## Atención a la diversidad

- Las tareas tienen un **núcleo obligatorio** y **ampliaciones** opcionales para quien quiera profundizar.
- Se respetan los ritmos de aprendizaje: las entregas tienen plazos amplios y existe una [convocatoria de recuperación](evaluacion.md#recuperacion).
- Las adaptaciones de acceso que corresponda (tiempo, formato, herramientas) se aplicarán según el informe del departamento de orientación.

## Recursos

- Ordenador con Linux, Windows o macOS y conexión a Internet. El software es gratuito: está detallado en [Entorno de trabajo](entorno-de-trabajo.md).
- Cuenta personal en GitHub (puedes solicitar las ventajas educativas de GitHub Education).
- Apuntes, ejemplos y vídeos enlazados en cada unidad.
