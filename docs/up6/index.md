# UP6 · Diagramas de clases

El diagrama de clases es el plano de un sistema orientado a objetos: muestra qué clases hay, qué saben, qué hacen y cómo se relacionan. En esta unidad aprenderás a leerlo, a dibujarlo a partir de una especificación y a pasar del diagrama al código y del código al diagrama con herramientas.

| | |
|---|---|
| **Resultado de aprendizaje** | RA5 · Genera diagramas de clases valorando su importancia en el desarrollo de aplicaciones y empleando herramientas específicas |
| **Criterios** | a, b, c, d, e, f |
| **Duración** | 15 horas · semanas 25–29 · 3.ª evaluación |
| **Peso del RA** | 15 % de la nota del módulo |

## Objetivos

- Repasar los conceptos de la programación orientada a objetos y relacionarlos con UML.
- Interpretar la notación de clases, atributos, métodos, visibilidad y multiplicidad.
- Distinguir y aplicar asociación, agregación, composición, herencia, realización y dependencia.
- Trazar diagramas de clases a partir de especificaciones en lenguaje natural.
- Generar código Java desde un diagrama y un diagrama desde código Java (ingeniería inversa).
